# 错误码定义

| 错误码 | 含义 | 触发条件 | 容器行为 |
|--------|------|---------|---------|
| 1001 | Tab ID 重复注册 | 两个 Tab 使用了相同的 id | 拒绝第二个注册，Toast 警告 |
| 1002 | minContainerVersion 不满足 | 容器版本 < Tab.minContainerVersion | 拒绝加载，提示"请升级客户端" |
| 1003 | 缺失必填字段 | id / displayName / icon / route / version 任一为空或不合法 | 拒绝加载 |
| 1004 | 生命周期回调超时 | 任一回调执行超过 5 秒 | 显示兜底页面 |
| 1005 | 生命周期回调抛异常 | onResume / onPause 等方法内部 crash | 显示兜底页面，打印日志 |
| 1006 | 权限不足 | Tab 声明的权限未被授予 | 拒绝加载，提示用户授权 |

## 兜底页面

当 1004（超时）或 1005（异常）发生时，容器为该 Tab 显示兜底页面，提示用户"该功能暂不可用"。其他 Tab 不受影响。

## 错误排查优先级

1. **1001**：检查是否多个 Tab 用了同一个 id 字符串
2. **1002**：检查 minContainerVersion 设置是否合理，或引导用户升级
3. **1003**：检查 TabDefinition 所有必填字段是否已赋值
4. **1004**：检查 onCreate / onResume 是否有耗时操作（网络请求应异步）
5. **1006**：检查 AndroidManifest.xml 是否声明了对应权限

## 错误码不中断容器

所有错误码的处理原则：**不影响其他 Tab 的正常运行**。一个 Tab 出错，其他 Tab 照常使用。
